Step-by-step guides for common HR operations in JMRi ERP (Odoo). You can also ask the Chat Assistant for help with any of these.

🔐 How to Login to JMRi ERP

• Public Address: https://oerp.jmrinfotech.com/ • Local Address: http://192.168.1.80:8069/ • Username: Your JMR Email Id • Password: Your own Password

🔑 How to Change & Reset Password

Method 1: Login → Top right menu → Preferences → "Change Password" Method 2: Odoo web page → Enter email → "Reset Password" → Link sent to email

📋 How to Apply Leaves

1. Go to: Human Resources → Leaves → Leave Request 2. Choose Leave Type (Casual, Sick, Emergency, Maternity, Paternity, etc.) 3. Set Start Date and End Date (Partial Leave option available) 4. Enter Reason for Leave 5. Click Save and Confirm 6. Leave Request Number auto-generated, email sent to Manager 7. Manager approves/refuses at: Leaves → Leave Request To Approve

⏰ How to Apply Attendance Regularisation

⚠️ Can ONLY be applied for Absent Days 1. Go to: Human Resources → Leaves → Attendance Regularisation → Create 2. Choose Type: On Duty or Work From Home 3. Set Start Date and End Date 4. Enter Reason for Regularisation 5. Click Save and Confirm → Email sent to Manager

🔄 How to Apply Comp-Off Request

1. Go to: Human Resources → Leaves → Comp-Off Request → Create 2. Choose Type: Weekend Days or Holidays 3. Choose Comp-Off Date 4. Enter Reason, Save and Confirm 5. Once Approved: Leaves will NOT be deducted

📊 How to Create Timesheet Entries

Step 1 — Create: Human Resources → Time Tracking → My Current Timesheet → Create Select period (weekly/monthly), set dates, Add Lines for projects, enter hours. Step 2 — Submit: Save & Submit to Manager Step 3 — Manager Approval: Human Resources → Time Tracking → Timesheets to Validate Manager can Approve or Refuse.

✈️ How to Apply Travel Request

1. Project Manager creates Resource Allocation → Trip ID generated 2. Email notification sent to Employee (CC: Project Manager) 3. HR Travel Desk creates Travel Card at: HR → Travel Desk → Travel Card 4. Employee creates Travel Request linked to Travel Card 5. Update Travel Card info on return (Returned or Lost)

📝 How to Create Manpower Requisition (MRF)

1. Go to: Human Resources → Recruitment → Resource Requisition → Create 2. Fill Requested Date & Target Closure Date 3. Select Job Position, enter Number of Positions 4. Add: Job Description, Qualifications, Skills 5. Save & Submit MRF → Tracking ID: "MRF/15-16/MM/000"

🎯 How to Create Employee Lead

1. Go to: Human Resource → Lead Generation → Lead → Create 2. Enter Subject describing the lead info 3. Account Name is Mandatory (check existing or create new) 4. Fill: Contact Name, Email, Phone, Address details 5. Complete Opportunity Information and Save

How Leave Balance is Calculated
• Allocated = Total days allocated (type='add', state='validate') • Used = Total days taken (type='remove', state='validate') • Balance = Allocated − Used Each leave type is tracked separately. Ask the chatbot: "What is my leave balance?" to see all your balances.
